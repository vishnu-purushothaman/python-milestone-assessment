# Student Marks Management System

A simple Python program that manages student marks, calculates results and displays a summary.

#  Features
- Stores Student ID, Name, Python, SQL and AI marks
- Calculates Total, Average and Grade
- Shows PASS (average >= 40) or FAIL (average < 40)
- Shows the student with the highest average
- Lists students with an average above 75

# Grading
Average	Grade
80 and above	A
60 – 79.99	B
40 – 59.99	C
Below 40	D
Concepts Used

Lists, Dictionaries, Functions, Conditional Statements, Loops, List Comprehension

# How to Run

python question1.py
