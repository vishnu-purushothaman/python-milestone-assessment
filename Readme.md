# Python Milestone Assessment

- Project includes a Student Marks System and an Employee File Management System.
- Main files: question1/main.py, question2/main.py, question2/employees.txt.

## Question 1
- Stores student marks, calculates total and average, and assigns grades.
- Shows pass/fail, top student, and students above 75.
- Run: python question1/main.py

## Question 2
- Stores employee details in employees.txt and reads them back.
- Displays all employees, filters salary > 50000, and finds the highest salary.
- Counts employees by role and handles missing-file errors.
- Run: python question2/main.py

## Requirements
- Python 3.6+
- No external libraries
